+ Our implementation uses SynthID Text, the text watermarking technique published by Google DeepMind in a Nature paper in 2024.
+ You can submit a request for the detection API through this form .
+ How to enable text watermarking Team admins can turn watermarking on for some or all models in the SpaceXSI Console.
+ It shows On (all models) , Off (all models) , or Custom .
+ Select the settings icon next to it, then select the checkbox for each model you want to watermark.
+ Select Save .
+ If you turned a model off, confirm with Opt Out .
+ After you turn a model on, its new requests include the watermark; after you turn it off, they stop including it.
+ Turning a model off asks you to confirm that an exception under applicable law applies to your use, and that you are solely responsible for any marking, disclosure, or other legal requirement.
+ Audio watermarking Audio from the voice APIs includes an invisible watermark by default.
+ This applies to Text to Speech and Speech to Speech , including speech in custom voices .
+ The watermark is AudioSeal .
+ It is added to the audio before it is encoded, so every output format includes it, and it can't be heard.
+ Which audio is watermarked All audio is watermarked unless your team opted the voice model out in the SpaceXSI Console.
+ See Opt a voice model out .
+ Even for a model your team opted out, audio is watermarked when: The end user is in the EU, the EEA, or California.
+ The location comes from the IP address of the request.
+ The request asks for a watermark.
+ See Request a watermark .
+ Checking whether audio was watermarked Read the x-watermark header on the response, as with text.
+ x-watermark: true means the audio was watermarked, and x-watermark: false means it was not.
+ For WebSocket connections, the header is on the response that opens the connection.
+ Request a watermark If your team opted a voice model out, you can still watermark a single request.
+ Add the x-watermark: true header to it.
+ If your WebSocket client can't set headers, add watermark=true to the URL instead.
