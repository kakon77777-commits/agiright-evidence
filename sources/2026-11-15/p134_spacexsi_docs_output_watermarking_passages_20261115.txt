It is applied while the model generates text: it slightly shapes which tokens the model picks, so it adds no characters, markup, or hidden text to the response. Our implementation uses SynthID Text, the text watermarking technique published by Google DeepMind in a Nature paper in 2024. Detection is statistical. SpaceXSI scores a piece of text against the watermark and reports whether it is watermarked, not watermarked, or uncertain. Longer text gives a stronger signal. Access to watermark detection is granted by application. You can submit a request for the detection API through this form . Which audio is watermarked All audio is watermarked unless your team opted the voice model out in the SpaceXSI Console. See Opt a voice model out . The request asks for a watermark. See Request a watermark .
