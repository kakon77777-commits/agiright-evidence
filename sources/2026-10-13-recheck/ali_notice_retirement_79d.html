[Model Studio]  Notice of Retirement for Selected Legacy Snapshot Models
Jun 08, 2026
Alibaba Cloud Model Studio
Affected Time
2026-10-10 00:00:00 (UTC+08)  [Subject to the actual change time]
Change Details
To continuously enhance model performance and service experience while optimizing underlying resource management, Alibaba Cloud Model Studio will retire the snapshot models listed in the table below on October 10, 2026. The detailed retirement list and recommended replacement models are as follows:
 
 
❗️Important Notice: Please be advised that Alibaba Cloud Model Studio will continue to undergo rapid iterations and release higher-performing models between the publication of this notice and the actual retirement dates. Consequently, the replacement recommendations provided in this notice will not be frequently updated with the release of new models. We highly recommend regularly visiting the Model Gallery on Alibaba Cloud Model Studio during your migration and daily operations to ensure you can flexibly select the latest and most suitable models for your specific business needs.
 
Change Impact
Upon retirement, these models will no longer support inference, and any applications or services continuing to call them will fail to receive
responses. If you are currently using any of these models, please ensure that you complete the API migration, parameter tuning, and business
validation before October 10, 2026, to avoid any disruption to your production services.
Additionally, the corresponding models supported by the Coding Plan and Token Plan listed above will also be retired simultaneously. If you
have purchased prepaid resource packages, you may submit a support ticket to request a pro-rata refund for the unused resources.
