Alibaba Cloud Bailian Retires Models, 36 Qwen and Related Models Removed

Alibaba Cloud Bailian has retired a batch of models. APIYI’s Qwen series is a direct pass-through of the official Alibaba Cloud API, so 36 models are removed in sync: early Qwen3 / Qwen-VL / Qwen3-Coder versions plus the DeepSeek and GLM models hosted on Bailian. Switch to a model that is still listed.

2026/10/11 00:46 (UTC+8) · Service Notice · Alibaba / DeepSeek / Zhipu ⏸ Alibaba Cloud Bailian has retired a batch of models; APIYI removes the following 36 in sync APIYI’s Qwen series is a direct pass-through of the official Alibaba Cloud Bailian API, so models go live and retire together with the official site. Requests to these model names will no longer work. Please switch the model name in your code to one that is still listed; see Model Pricing.
