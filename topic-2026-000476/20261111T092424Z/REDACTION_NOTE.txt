rendered.html in this folder stored the Cloudflare block page that the rendering browser received instead of the New York State page (HTTP 403 class block, "Sorry, you have been blocked"). That page contains a hidden element (id "cf-footer-ip") holding the visitor's IP address, which is the address of the machine that took the snapshot. On 2026-11-11, before the push to this public repository, the address was replaced by the text "[IP address redacted]". Nothing else in the file was changed. raw.html in this folder is the page as the tool's own fetch received it (HTTP 200, the article text) and holds no such element.
